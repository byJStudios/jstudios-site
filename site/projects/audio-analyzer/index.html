Audiodateien technisch vergleichen, ohne sie einzeln in einem Player zu öffnen. Audio Analyzer liest die verfügbaren Metadaten lokaler Dateien und stellt sie in einer gemeinsamen Tabelle dar.

TkinterTinyTag

Open Source · MIT License · Bestandsprojekt

Quellcode auf GitHub ↗Installation & Dokumentation

01 / FUNKTIONEN

Was das Projekt bietet.

01

Dateiauswahl

Mehrere MP3-, WAV-, FLAC-, OGG-, M4A- oder WMA-Dateien über den Dateidialog auswählen.

02

Metadaten

Dauer, Bitrate, Abtastrate und Kanalzahl auslesen, soweit das Format und TinyTag sie bereitstellen.

03

Übersicht

Dateinamen und technische Werte nebeneinander vergleichen; fehlende Werte und Lesefehler werden angezeigt.

02 / PREVIEW

Technische Daten auf einen Blick.

Originaloberfläche mit vier synthetischen Testdateien.

03 / WORKFLOW

Auswählen. Auslesen. Vergleichen.

01

Dateien hinzufügen

Wähle eine oder mehrere lokale Audiodateien.

02

Werte prüfen

Vergleiche die von TinyTag gelesenen Angaben in der Tabelle.

03

Liste zurücksetzen

Leere die Ansicht, ohne die Originaldateien zu verändern.

Entwicklungsstand

Historisches Bestandsprojekt. Der bereinigte Quellcode steht unter der MIT-Lizenz zur Verfügung. Der Anwendungsstart wurde mit leeren bzw. synthetischen Daten unter Windows geprüft. Die Anwendung liest Metadaten; sie prüft weder Audioqualität noch tatsächliche Codec-Authentizität. Die Formatspalte basiert auf der Dateiendung. Eine vollständige Prüfung aller unterstützten Formate und Plattformen steht aus.
