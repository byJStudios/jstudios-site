VidMatch History Importerby JStudios

Wiedergabeverläufe rekonstruieren

Wandelt YouTube-Wiedergabeverläufe aus Google Takeout in ein JSON um, das sich in VidMatch importieren lässt, eine Anwendung zur Erfassung und Auswertung von Videowiedergabezeiten. Das Werkzeug ergänzt Videometadaten und schätzt Wiedergabezeiten.

01 / DATENFLUSS

Der Weg eines historischen YouTube-Aufrufs

Ein Takeout-Export enthält Video-Aufrufe, aber normalerweise keine tatsächlich gemessene Wiedergabedauer pro Aufruf. Der Importer verbindet diese historischen Einträge mit Videometadaten, ohne bestehende echte VidMatch-Messwerte zu überschreiben. Die berechneten Wiedergabezeiten sind Schätzungen, keine Messwerte.

01

Takeout-Parser

Liest das unterstützte deutsche HTML-Format, filtert erkannte Werbeeinträge und sortiert die Ereignisse chronologisch. Zeitangaben werden auf CET/CEST des jeweiligen Ereignisdatums umgerechnet.

02

Metadaten mit Cache

YouTube Data API v3 fragt Video- und Kanalinformationen in Batches ab. yt-dlp steht alternativ oder als gezielter Fallback zur Verfügung. Metadaten werden lokal gecacht.

03

Konservative Rekonstruktion

Bekannte Videolänge als Ausgangswert, begrenzt durch den Abstand zum nächsten Video. Ohne bekannte Länge wahlweise eine Sekunde oder Abstand zum Folgevideo, gedeckelt auf 30 Minuten.

04

Bestehende Messwerte erhalten

Vorhandene VidMatch-Schlüssel bleiben beim Merge erhalten. Rekonstruierte Ereignisse desselben Videos in derselben Stunde können zusammengefasst werden; fehlende Metadaten führen standardmäßig zum Überspringen.

02 / REKONSTRUKTION

Import und Rekonstruktion im Beispiel

380 sGeschätzte Wiedergabezeit

Wie aus drei Aufrufen 380 Sekunden werden

Im Offline-Test sind drei fiktive Aufrufe jeweils 180 Sekunden lang. Die Startabstände betragen 80 und 120 Sekunden. Der Algorithmus setzt daher 80 + 120 + 180 = 380 geschätzte Sekunden an. Das Log zeigt zwei Kürzungen durch Folgeaufrufe.

03 / BEDIENUNG

Vom Takeout-Export zum JSON

01

Dateien auswählen

Lokalen HTML-Verlauf, optional vorhandenen VidMatch-Export und neue Ausgabedatei wählen.

02

Metadaten-Modus festlegen

Eigener API-Key oder yt-dlp; Cache und konservatives Verhalten bei fehlenden Angaben konfigurieren.

03

Import bauen

JSON und Bericht erzeugen. Ergebnis vor dem eigentlichen Import prüfen; niemals die einzige Sicherung überschreiben.

Hinweise zur Nutzung

Die Wiedergabezeit wird geschätzt. Unterstützt wird das implementierte deutsche Takeout-HTML-Format. Metadaten werden bei Bedarf online abgerufen; API-Key und optional ausgewählte Browser-Cookies bleiben lokal. Der Offline-Test prüft die Rekonstruktion, nicht die Live-API oder den vollständigen VidMatch-Import.
